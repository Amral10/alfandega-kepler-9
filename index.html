MANUAL DO OPERADOR

Seu primeiro contato com o terminal

SQL é a linguagem usada para conversar com um banco de dados. Escreva uma consulta e selecione Executar SQL para ver a resposta.

SELECT nome, especie, destino
FROM viajantes
WHERE origem = 'Terra';

SELECT escolhe as colunas, FROM indica a tabela e WHERE filtra os registros.

Use Ctrl + Enter (ou ⌘ + Enter) no editor para executar. Cada execução exibe até 200 linhas, compartilhadas entre seus resultados. Consultas acima de 5 segundos são interrompidas.

Na demonstração você pode alterar os dados. Reiniciar restaura o banco original. Cancelar uma consulta preserva a última execução concluída. Seu progresso é salvo neste navegador; o relógio continua correndo ao sair ou recarregar.

O nível fácil ensina a criar e consultar um banco vazio. Use os exemplos de cada tarefa e o glossário do terminal. A demonstração permanece disponível para explorar um banco pronto. O nível médio já permite fiscalizar viajantes, registrar rascunhos por SQL e confirmar decisões. Os cadastros são somente leitura; apenas rascunhos do viajante atual podem ser alterados. O nível avançado exige junções, agrupamentos e distinção. O resumo da campanha reúne seus resultados.
